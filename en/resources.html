Resources

Software, the sources behind the methods, and useful services. Everything is free or has a free option.

#Software and tools

  • Blender — free 3D modeling software. We work in Blender 5.2 LTS (release notes).
  • model-viewer — Google’s web component that shows a GLB model in the browser and opens AR on a phone (block 8).
  • Any free QR code generator — to link to your published AR page. Generate the code only for the final https://… address.
  • Any quick GLB viewer (in the browser or local) — to check the export from block 7.

#Sources of the methods

The club’s program builds on the following materials. Most are in English; we learn Blender’s terms in English anyway, so this is good practice.

  • Imphenzia, Workshops — a five-hotkey blockout and face colors without UV unwrapping: imphenzia.com/workshops. For Block 1.
  • Blender Guru, Donut tutorial — one small object goes through the full cycle; every step is saved as a separate file: blenderguru.com. For Block 1 and Block 5.
  • GameDev.tv / Grant Abbitt, Blender Low Poly Characters — a quick character build-out and references: gamedev.tv. For Block 3 and Block 5.
  • Grant Abbitt, Easy Rigging Using Rigify — a 15-minute repeatable rigging sequence: YouTube. For Block 6.
  • CG Cookie, 8 Tips for Clean Topology in Blender — edge flow through simple shapes, the MatCap check: blog.cgcookie.com. For Block 4.
  • StraySpark, Blender 5.x to Unreal Engine 5.7 (2026) — an up-to-date pipeline checklist: strayspark.studio. For Block 7.
  • Google for Developers, AR with model-viewer — Quick Look and Scene Viewer from a web page: developers.google.com. For Block 8.
  • Project-based learning — why learning through your own project works better: Wikipedia.
