Where Am I?

Screen state plus a key you press — what happens? Train telling Object Mode from Edit Mode before it becomes a source of confusion.

Open the exercise

#What it trains

Fast, mistake-free reading of Blender's screen state: which mode am I in right now, and what will this key or click actually do. This isn't about memorizing a hotkey list — it's the habit of checking the state first, then pressing. The exercise illustrates Block 0 with short scenarios instead of a long list.

#How it works

Each round is a short description of the screen state (sometimes including Object Mode or Edit Mode) and an action you're about to take: a mouse move, a click, a hotkey. Pick what actually happens out of four options. After you pick, a short explanation appears under every option — for the right answer and the wrong ones alike, so you see not just "yes" or "no" but why.

The scenarios cover the whole block: viewport navigation (orbit/pan/zoom, Home), the orientation gizmo and numpad views, selection in Object Mode (click, Shift+click, clicking empty space), Tab between Object and Edit Mode, switching selection modes in Edit Mode, box select (B), and clicking an object's name in the Outliner.

#What we take from it

  • "The tool isn't working" usually means "I'm in the wrong mode." That check is the first habit worth building, before block 1, where it decides whether Extrude or Mirror even does anything.
  • Object Mode and Edit Mode aren't a fine distinction — they're different worlds: the same key means something different in each (or nothing at all).
  • The orientation gizmo and the numpad number keys give you an exact view instantly — faster and more reliable than eyeballing a rotation with the mouse.
  • The Outliner isn't just a list: clicking a name there selects the object the same way clicking it in the viewport would, even when it's hidden behind something or out of frame.

Run a few rounds before opening Blender for the first time in session — that way the first few minutes go into the model itself, not into hunting for the right button.
