## Програми й інструменти

- [Blender](https://www.blender.org/download/) — безкоштовна програма для 3D-моделювання. Ми працюємо в Blender 5.2 LTS ([про випуск](https://www.blender.org/press/blender-5-2-lts-release/)).
- [model-viewer](https://modelviewer.dev/) — веб-компонент Google, що показує GLB-модель у браузері й відкриває AR на телефоні ([[block:8|блок 8]]).
- Будь-який безкоштовний генератор QR-кодів — для посилання на опубліковану AR-сторінку. Генеруйте код лише на фінальну адресу `https://…`.
- Будь-який швидкий переглядач GLB (у браузері чи локально) — щоб перевірити експорт із [[block:7|блоку 7]].

## Джерела методик

Програма клубу спирається на такі матеріали. Більшість — англійською; терміни в Blender ми все одно вчимо англійською, тож це хороша практика.

- **Imphenzia, Workshops** — блокаут за п’ятьма гарячими клавішами й колір по гранях без UV-розгортки: [imphenzia.com/workshops](https://imphenzia.com/workshops). Для [[block:1]].
- **Blender Guru, Donut tutorial** — один невеликий об’єкт проходить повний цикл; кожен крок зберігається окремим файлом: [blenderguru.com](https://www.blenderguru.com/posts/blender-donut-v5-tutorial). Для [[block:1]] і [[block:5]].
- **GameDev.tv / Grant Abbitt, Blender Low Poly Characters** — швидкий білдаут персонажа й референси: [gamedev.tv](https://gamedev.tv/courses/blender-low-poly-characters). Для [[block:3]] і [[block:5]].
- **Grant Abbitt, Easy Rigging Using Rigify** — 15-хвилинна відтворювана послідовність рігінгу: [YouTube](https://www.youtube.com/watch?v=RdTuAY23vzk). Для [[block:6]].
- **CG Cookie, 8 Tips for Clean Topology in Blender** — edge flow через прості форми, MatCap-перевірка: [blog.cgcookie.com](https://blog.cgcookie.com/posts/guide-to-clean-topology/). Для [[block:4]].
- **StraySpark, Blender 5.x to Unreal Engine 5.7 (2026)** — актуальний чекліст пайплайну: [strayspark.studio](https://www.strayspark.studio/blog/blender-5-to-unreal-engine-57-asset-pipeline-2026). Для [[block:7]].
- **Google for Developers, AR with model-viewer** — Quick Look і Scene Viewer з веб-сторінки: [developers.google.com](https://developers.google.com/ar/develop/webxr/model-viewer). Для [[block:8]].
- **Project-based learning** — чому вчитися на власному проєкті ефективніше: [Wikipedia](https://en.wikipedia.org/wiki/Project-based_learning).
